# InnCad Plus — downloads

**InnCad Plus** is a free parametric CAD for 3D printing enthusiasts, on the FreeCAD 1.1.3 engine: sketches, features
and assemblies, tools that turn an STL back into a real part, and a built-in link to your AI (Claude Code, Codex or
Gemini CLI) that rebuilds an STL as a part you can save as STEP.

This repository holds the downloads only. Get the latest version from
**[Releases](https://github.com/Igr11/InnCadPlus-releases/releases/latest)**.

| System | File | |
|---|---|---|
| macOS 13 or newer, Apple Silicon (M1 or newer) | `InnCadPlus-<version>-macos-arm64.dmg` | Drag InnCadPlus.app onto Applications |
| Windows 10 / 11, 64-bit (x64) | `InnCadPlus-<version>-windows-x64.zip` | Portable: no installation needed. Unzip and use |

- **Mac, first launch:** the app is not notarized by Apple. Click Done (not Move to Trash), open System Settings ▸
  Privacy & Security and click **Open Anyway**, then confirm with your password. Needed only once.
- **Windows:** unzip to a short path with Latin letters only and run `InnCadPlus.exe`.
- No FreeCAD installation is needed: the engine is inside. Manuals (EN, RU) and What's New are attached to each release.
- Already use FreeCAD 1.1? The same tools come as a workbench: [InCad](https://github.com/Igr11/InCad).
- Questions and bug reports: [InCad issues](https://github.com/Igr11/InCad/issues). Attach the log (chapter 11 of
  the manual).


## Licenses

InnCad Plus is free to use. Its own code, the [InCad workbench](https://github.com/Igr11/InCad), is open source
(LGPL 2.1 or later, as FreeCAD). The app bundles open-source components, unmodified as built by conda-forge, each

endorsed by the FreeCAD project.

# InnCad Plus — загрузки

**InnCad Plus** — бесплатная параметрическая САПР для энтузиастов 3D-печати на движке FreeCAD 1.1.3: эскизы, фичи и
сборки, инструменты, которые превращают STL обратно в настоящую деталь, и встроенная связь с вашим ИИ (Claude Code,
Codex или Gemini CLI), который перестраивает STL в деталь, готовую к сохранению в STEP.

Здесь только файлы для скачивания. Последняя версия — в **[Releases](https://github.com/Igr11/InnCadPlus-releases/releases/latest)**.

| Система | Файл | |
|---|---|---|
| macOS 13 и новее, Apple Silicon (M1 и новее) | `InnCadPlus-<версия>-macos-arm64.dmg` | Перетащите InnCadPlus.app в «Программы» |
| Windows 10 / 11, 64 бит (x64) | `InnCadPlus-<версия>-windows-x64.zip` | Portable: установка не нужна. Распакуйте и пользуйтесь |

- **Mac, первый запуск:** программа не заверена (notarized) в Apple. Нажмите «Готово» (не «Переместить в Корзину»),
  откройте Системные настройки ▸ Конфиденциальность и безопасность и нажмите **«Всё равно открыть»**, подтвердите
  паролем. Это нужно один раз.
- **Windows:** распакуйте в короткий путь без кириллицы и запустите `InnCadPlus.exe`.
- FreeCAD ставить не нужно: движок внутри. Руководства (EN, RU) и «Что нового» приложены к каждому выпуску.
- Уже работаете во FreeCAD 1.1? Те же инструменты есть в виде верстака: [InCad](https://github.com/Igr11/InCad).
- Вопросы и сообщения об ошибках: [InCad issues](https://github.com/Igr11/InCad/issues). Приложите журнал (глава 11
  руководства).
