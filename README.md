# ProstoCAD — downloads

*ProstoCAD was called InnCad Plus until version 0.11. Home page: https://prostocad.com*

**ProstoCAD** is a free parametric CAD for 3D printing enthusiasts, on the FreeCAD 1.1.3 engine: sketches, features
and assemblies, tools that turn an STL back into a real part, and a built-in link to your AI (Claude Code, Codex or
Gemini CLI) that rebuilds an STL as a part you can save as STEP.

This repository holds the downloads only. Get the latest version from
**[Releases](https://github.com/Igr11/ProstoCAD-releases/releases/latest)**.

| System | File | |
|---|---|---|
| macOS 13 or newer, Apple Silicon (M1 or newer) | `ProstoCAD-<version>-macos-arm64.dmg` | Drag ProstoCAD.app onto Applications |
| Windows 10 / 11, 64-bit (x64) | `ProstoCAD-<version>-windows-x64.zip` | Portable: no installation needed. Unzip and use |

- **Mac, first launch:** the app is not notarized by Apple. Click Done (not Move to Trash), open System Settings ▸
  Privacy & Security and click **Open Anyway**, then confirm with your password. Needed only once.
- **Windows:** unzip to a short path with Latin letters only and run `ProstoCAD.exe`.
- No FreeCAD installation is needed: the engine is inside. Manuals (EN, RU) and What's New are attached to each release.
- Already use FreeCAD 1.1? The same tools come as a workbench: [ProstoCAD for FreeCAD](https://github.com/Igr11/ProstoCAD) (formerly InCad).
- Questions and bug reports: [ProstoCAD issues](https://github.com/Igr11/ProstoCAD/issues). Attach the log (chapter 11 of
  the manual).

# ProstoCAD — загрузки

**ProstoCAD** — бесплатная параметрическая САПР для энтузиастов 3D-печати на движке FreeCAD 1.1.3: эскизы, фичи и
сборки, инструменты, которые превращают STL обратно в настоящую деталь, и встроенная связь с вашим ИИ (Claude Code,
Codex или Gemini CLI), который перестраивает STL в деталь, готовую к сохранению в STEP.

Здесь только файлы для скачивания. Последняя версия — в **[Releases](https://github.com/Igr11/ProstoCAD-releases/releases/latest)**.

| Система | Файл | |
|---|---|---|
| macOS 13 и новее, Apple Silicon (M1 и новее) | `InnCadPlus-<версия>-macos-arm64.dmg` | Перетащите ProstoCAD.app в «Программы» |
| Windows 10 / 11, 64 бит (x64) | `InnCadPlus-<версия>-windows-x64.zip` | Portable: установка не нужна. Распакуйте и пользуйтесь |

- **Mac, первый запуск:** программа не заверена (notarized) в Apple. Нажмите «Готово» (не «Переместить в Корзину»),
  откройте Системные настройки ▸ Конфиденциальность и безопасность и нажмите **«Всё равно открыть»**, подтвердите
  паролем. Это нужно один раз.
- **Windows:** распакуйте в короткий путь без кириллицы и запустите `ProstoCAD.exe`.
- FreeCAD ставить не нужно: движок внутри. Руководства (EN, RU) и «Что нового» приложены к каждому выпуску.
- Уже работаете во FreeCAD 1.1? Те же инструменты есть в виде верстака: [ProstoCAD for FreeCAD](https://github.com/Igr11/ProstoCAD) (formerly InCad).
- Вопросы и сообщения об ошибках: [ProstoCAD issues](https://github.com/Igr11/ProstoCAD/issues). Приложите журнал (глава 11
  руководства).

## Лицензии

ProstoCAD бесплатен. Он построен на [верстаке InCad](https://github.com/Igr11/InCad) с открытым кодом (LGPL 2.1 или
новее, как у FreeCAD); дополнения Plus (инструменты STL, связь с ИИ) не открыты. В программе — открытые компоненты без изменений, собранные conda-forge, каждый под своей
лицензией: FreeCAD 1.1.3 (LGPL 2.1+), Open CASCADE (LGPL 2.1), Qt 6 / PySide6 (LGPL 3) и другие. В каждом выпуске —
`THIRD-PARTY-NOTICES.txt` (все компоненты, тексты лицензий и исходники) и исходный код всех GPL-компонентов. Не менее
трёх лет по запросу предоставляем полный исходный код любого GPL- или LGPL-компонента:
[спросить здесь](https://github.com/Igr11/InCad/issues). ProstoCAD — независимый проект, не связанный с командой
FreeCAD.
